# Vedanti Dalane — Personal Portfolio

A responsive portfolio website built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `Personal-Portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing — personalize these items
- Replace `images/profile-placeholder.svg` with your own photo. Update the image path in `index.html` if you use a different filename.
- Add your actual phone number.
- Replace the LinkedIn and GitHub placeholder URLs with your profile URLs.
- Add `Vedanti_Dalane_Resume.pdf` inside the `resume` folder.
- Verify experience dates, role descriptions, and project descriptions.
- Add your real GitHub and live-demo links to the project cards if available.

## Contact form
The form validates the entered details with JavaScript and opens the visitor's default email application using a `mailto:` link. It does not send or store messages on a server. A backend or form service is needed for direct website submissions.

## Files
- `index.html` — page structure and content
- `css/style.css` — responsive styling
- `js/script.js` — navigation and form validation
- `images/` — profile image placeholder
- `resume/` — add your PDF resume here
